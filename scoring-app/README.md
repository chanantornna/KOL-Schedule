# ระบบรวมคะแนนการแข่งขัน (Scoring App)

เว็บแอพรวมคะแนนการแข่งขันแบบยืดหยุ่น กำหนดเกณฑ์เอง เพิ่ม/ลบกรรมการและผู้เข้าแข่งขันได้ เหมาะกับงานแข่งขัน/นำเสนอทั่วไป (ไม่ผูกกับงานใดงานหนึ่ง)

## ความสามารถ

- ตั้ง **ชื่องาน** เองได้
- **เกณฑ์การให้คะแนน (criteria)**: เพิ่ม/ลบ/แก้ชื่อหัวข้อ, น้ำหนัก (%), คะแนนเต็มของแต่ละหัวข้อ
- **กรรมการ**: เพิ่ม/ลบ/แก้ชื่อได้ไม่จำกัด
- **ผู้เข้าแข่งขัน**: เพิ่ม/ลบได้
- คำนวณอัตโนมัติ: Total ต่อกรรมการ, Grand Total, และจัดอันดับ
- ดาวน์โหลด CSV (สรุปอันดับ / รายละเอียดทุกหัวข้อ)
- ส่งออก/นำเข้าไฟล์ `.json` เพื่อส่งต่อให้กรรมการท่านอื่น

## สูตรการคำนวณ

- **Total ต่อกรรมการ** = Σ ( คะแนนดิบ ÷ คะแนนเต็มของหัวข้อ × น้ำหนัก )
  - ถ้าน้ำหนักรวม = 100% ค่า Total จะเต็ม 100 พอดี
- **Grand Total** = ค่าเฉลี่ยของ Total จากกรรมการทุกคน
- **ลำดับ** = จัดอันดับจาก Grand Total มากไปน้อย (คะแนนเท่ากันได้ลำดับเดียวกัน)

## การใช้งานบนเว็บ (GitHub Pages)
